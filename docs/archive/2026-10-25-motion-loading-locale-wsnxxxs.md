## 本轮目标

为 Gallery 设计高级、简约、克制而流畅的过渡动画，美化加载过程，完善交互，各页面按需覆盖。看过线上后用户补充：线上与静态版差距大，所说的过渡更偏向“衔接加载”，并要求优化设置里的各语言界面，做到认为最好的效果。用户随后授权按规范归档、提交并推送；未授权部署。

## 改动

均在本轮一条英文提交中（提交号见 git log），只涉及本仓前端与构建工具。

- 动效层：新增 `site/motion.css`（最后一个样式表）与 `site/motion.js`。
  - 路由视图过渡：旧画面最多保留 300ms（含拉取页面代码），超时先过渡到新页面自己的载入状态。
  - 入场与反馈：内容逐项上浮，屏外的滚到再浮；侧栏只在换板块时上浮；忙过 160ms 的导航顶部出现细进度线。
  - 题库卡片图片与查看器舞台互为共享元素。
  - 筛选、排序、搜索用 FLIP 重排；面板切换单独上浮；分段控件选中底块滑动；题目卡有指针边缘光。
  - 图片解码显影与空框扫光；查看器载入层呼吸、上浮与消散；分屏窗格错开进场。
  - 对话框、菜单、提示条、灯箱的进出场；灯箱从缩略图放大，左右切换滑入。
  - 主题从开关处圆形铺开（`ui.js`）。
  - 指针停在平台页链接上时预取该页代码（`app.js`）。
  - `prefers-reduced-motion` 下全部关闭。
- 载入衔接：
  - 有脚本时，静态介绍成为开场卡片：标志、站名、中英各一句，下有流动细线，0.28s 后才浮现。
  - 首个页面从开场卡片交叉浮现；载入占位换成真实页面时也是一次交叉淡入，两屏位置不变的元素不重播。
  - `index.html`：import map 移入 head（样式之后）；`entry-boot.js`、`runtime-config.js` 移到 body 末尾，其后的内联脚本提前发出 data.json、catalog、session，参数与原先一致。`platform-api.js` 新增 `bootRead`，`app.js` 与 `platform.js` 各取一次。
  - `scripts/cache-bust.mjs`：在 import map 后为入口的静态依赖生成 modulepreload（本次 32 个，动态 import 除外），`test/cache-bust.test.mjs` 补了断言。
- 语言界面：
  - 语言开关改为两段式：当前语言在底块上，点哪一侧切哪一侧。切换时底块滑动，只淡化变化的文字（`i18n.js` 的 `setLocaleTransition` 钩子由 `motion.js` 注册）。
  - 英文缺空格：返回链接改为“Back to …”；盲评登录链接和条款、隐私里的邮箱与“See also”使用 `.en-gap`（`arena.js`、`legal.js`）。
  - 英文分段按钮不折行；英文榜单模型列加宽，不再横溢（`studio.css`、`platform.css`）。
  - 静态介绍不再被 i18n 反向改成“亿模亿样 亿模亿样”。
- 文档：`docs/DESIGN.md`「动效」整节改写；根目录 `HANDOFF.md` 记本轮。

## 决策

- 动效只用 opacity、transform、filter，运动中只用墨与灰；朱红仍只留给朱批。阴影只在浮层上。
- 等待时间的大头在模块串行加载和首批请求太晚发出，所以先改启动顺序，再做视觉衔接。
- 开场卡片保留静态介绍原文，作为无脚本读者与读屏内容。
- 线上 `/api/catalog` brotli 后约 310KB、首访 3–4s，属后端范畴，本轮不改。
- 提交沿用本仓近期惯例：负责人 wsnxxxs 的 noreply 身份，一条英文简单句，不加联合署名。
