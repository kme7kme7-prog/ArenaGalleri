## 本轮目标

用户反馈：管理员后台改作品信息后，题目页两件 Claude Sonnet 5.5 · High 作品仍收在同一组；管理员后台不能直接改作品所属题目。

## 改动

- `site/work-management.js`：作品管理弹窗新增「所属题目」下拉（公开题目与已读取的管理题目），仅投稿作品且当前管理员可决定时启用，改动时随 meta 提交 `task`；数据包作品、自己发布的作品禁用并说明原因。
- `site/work-fields.js`：标题仍为「模型 · 档位」默认值时，改模型或档位会同步更新标题；默认标题统一由 `defaultTitle` 生成。
- 合组的主因在后端仓库管理后台弹窗（登记模型 ID 覆盖改名），同日在后端修复，见其归档。

## 决策

- 后端 `setMeta` 已支持管理员迁移投稿作品（连同票、对局、评论、表情），数据包作品拒绝迁移；前端只补入口，不改后端规则。
- 题目页按模型合组属既定设计，本轮不改合组规则。
