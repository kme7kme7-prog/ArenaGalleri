## 本轮目标

用户认为盲评只有顶栏一个「显示作品控件」总开关，靠提取注入收放控件适配得不好，要求加入可动态调整的对比框：一边可以完整展示，另一边可以收起。先出原型，用户确认后实现：去掉总开关，只看一件时不加投票限制。

## 改动

- `site/arena.js`：
  - 桌面中间分隔条可拖动（指针捕获，拖动时给两侧作品加遮罩，避免 iframe 吞掉移动事件），聚焦后可用方向键 / Home / End 调整，双击复位。拖到边缘 10% 内吸附收起，收起侧显示 44px 窄栏，点窄栏恢复上次比例。
  - 顶栏三个布局键与键盘 1 / 2 / 3（手机不响应）切换只看 A / 并排 / 只看 B；窗格标题栏另有「只看这件 / 恢复并排」按钮。每组开始复位为 50 : 50。
  - 去掉顶栏总开关，改为每件作品标题栏各自的「控件」按钮，只在该作品上报控件后出现，A、B 分别收放；手机端揭晓前看不到窗格标题栏，所以在 A / B 切换行放一个按钮，作用于当前作品。
- `site/platform.css`：分隔条、把手、读数、窄栏和布局键的样式，全部只在 >860px 生效；收起侧的 iframe 保持舞台全宽隐藏，作品不会收到极窄的视口，也不会重新载入。窗格标题栏用容器查询，窄时隐藏「投票后拆封」和「控件」文字。
- `docs/PRODUCT.md`、`docs/DESIGN.md`：补充盲评分屏与分侧控件的行为和样式；并排预览仍使用原来的总开关。

## 决策

- 用户已确认：去掉盲评顶栏总开关；桌面只看一件时不要求两件都看过才能投票。
- 每组复位 50 : 50，避免上一组的布局让人先入为主偏向某一边。
- 收起时不缩小作品视口：原型中的模拟作品在窄视口下出现死循环，真实作品也可能有类似问题。
