## 本轮目标

解决远端权威目录门禁使正常慢请求也长时间显示整页“正在连接展览馆”的问题，完成代码、回归与提交。保留后台可见性裁决，不用可能已撤下的包内目录掩盖故障。

## 改动

- 本归档随本轮英文提交保存。平台分开读取公开目录、轻量会话、统计；目录成功立即展示，题库局部骨架及失败恢复，榜单使用独立数据请求，未知计数不伪装成零。账号与统计迟到不清空同账号表单。
- 公开请求不带凭据，HTTP ETag 重验证；会话和统计 no-store。在途请求合并、15秒读取超时、一次自动恢复及 Retry-After 冷却；网络/焦点/手动恢复保留。旧后端单次 bootstrap 兼容，显式 API 故障不进入静态模式。
- 身份或角色切换清理私有记忆与覆盖层并忽略旧响应；401确认会话过期后立即恢复匿名统计；写操作废弃写前在途统计并重读。实际身份变化清理私有页面，单纯状态变化不销毁输入。
- 对齐远端本轮涉及的首页先绘制与装饰档案，不合并无关源码；保留已有个人署名与预览按需加载。更新部署检查、跨仓集成契约与架构/产品文档。
- 独立后台新增 catalog/session/activity、目录缓存与变更失效，保留旧 bootstrap；详见后台同轮归档。

## 决策

使用服务端纯公开缓存与每次重验证，避免持久化含用户权限的聚合快照。首次公开目录仍需服务端确认；同一页面刷新失败保留已验证内容。目录与身份独立，但写权限始终由后端校验。无需数据库迁移，不新增缓存服务。
