# 界面设计规范与风格

> 记录主站现有风格基线与工程约定。`site/studio.css` 是共用布局与视觉覆盖层，基础组件仍在 `style.css`、`platform.css`、`sandtable.css`、`exhibition.css`。

## 定调

像一间安静的深色展馆：墨色背景、细线分隔、左侧衬线标题与题目上下文，右侧紧凑的作品网格。作品卡片默认直接展示三维小模型，画布随卡片滚动。首页用动态标题、同题解答叠放卡组与提示词便签组织首屏，下方展示最近收录流动卡带；题库和平台功能沿用双栏布局。

大标题使用衬线；集合标题与作品名称使用无衬线。朱红只作「朱批」：批改、评定和你的选择，其余界面用墨与灰。默认深色，保留用户手动选择的浅色主题。

## Token

发起题目的资格提示沿用原生 sheet 弹窗与现有色彩变量，两项进度之间明确标注「或」。主操作为继续填写并附示例，盲评和上传为辅助入口；480px 以下进度及操作按钮改为单列，弹窗限制视口高度并可滚动。表单上方常驻资格说明和刷新进度，不仅在提交失败后提示。

颜色只通过 `:root` 与 `:root[data-theme="dark"]` 的变量使用；`index.html` 的内联脚本在首帧前写入 `data-theme`。

运行作品的舞台（在线预览、盲评、试加载）固定用 `#121211` 深底，不随主题变化，让作品自身的配色不受干扰。

## 字体

| 角色 | 字体变量 | 用在 |
| --- | --- | --- |
| 展示与标题 | `--serif`（宋体系） | 侧栏大标题、首页导语、步骤标题、对话框标题、盲评的 A / B 字母（斜体，窗格标题、载入层、手机切换器与投票按钮共用 `.ab` / `.pane-letter`） |
| 正文与界面 | `--sans`（系统无衬线） | 说明、表单、按钮、表格文字 |

侧栏标题 37px，题目卡片标题 18px；首页标题随窗口在 32–54px 间调整（手机27–36px），流动卡片标题 13px；右侧集合标题 20px，作品标题 16px。移动端侧栏 30px、作品标题 14px。数字使用 `tabular-nums`。

## 朱红的用法

文案是课堂口吻（题库、出题、一题多解），朱红就当「朱批」用，只留给有批改、评定意味的东西，数量少才有分量：

- **评定**：代表作印章（题目页封面作品的「代表」）、榜单前三名的衬线名次。
- **阅卷**：题目页「参与盲评」行动卡、盲评的「糊名」条与投票按钮悬停。
- **你的选择**：盲评揭晓后的「所选」印章与标题栏 2px 朱红线、勾选对比的描边与按钮、自己贴过的表情、选中文字的淡底。
- **批注**：存疑标记与原因、表单错误、无效输入、必填星号、检查清单的提示与失败、阶段条的失败、名额已满、危险操作、平台功能暂停提示条与待处理红点。
- **品牌**：Logo 缺口与首页标题末尾的句号。

其余一律用墨与灰：选中导航与分段控件是次级底色 + 墨字，选中芯片与分类卡片是次要色描边 + 次级底色，主要按钮是反色墨底（`--inv`），焦点环是墨色，输入框与搜索框聚焦是次要色描边，分类标签、编号、计数、「+N 件」、「来源」徽标、阶段条当前阶段、活跃图、榜单区间横条与沙盘工具都不用朱红。新增界面要用朱红时，先确认属于上面哪一类。

## 版式模式

- **首页海报**：牌堆与最近收录的图片窗口固定 16:10；按海报可见像素（alpha > 8）的外框等比缩放、居中，外框在窗口中占宽或高的 84%，四边至少留对应方向的 8%。不将海报内部透明空白重复计入留白，也不裁掉可见模型。首次加载前使用 84% 图片区域，加载后读取一次可见范围并缓存，同一作品仍共用一张海报。提示词在牌堆下方。
- **双栏外壳**：`.app-layout` 左侧 300px `.app-sidebar` 固定在顶栏下，可独立滚动；右侧 `.workspace` 随文档滚动。`pageStart` / `pageEnd` 为平台模块共用入口。
- **导航分工**：顶栏是全站导航，当前板块的入口用 `aria-current` 高亮（导航链接加淡底，头像加灰色描边与次级底色）；侧栏只放本板块的视图（`sideNav` 生成的 `.section-nav`），不重复顶栏；子页面（题目、作品预览、展厅/沙盘、上传、盲评）在顶栏提供唯一的「返回 X」（`backLink`），普通页位于品牌后，预览与盲评对局位于左端。X 是读者来自的页面；直接打开或从下级返回时退回上级。窄屏只显示「返回」，完整目标保留在链接提示中。题库分类写入地址 `#/questions/<分类>`，浏览器后退、前进及返回上一历史条目时恢复原滚动位置。同一板块内切换视图时侧栏保持不变。
- **首页**：左侧衬线动态标题、说明和主入口，右侧最多五张浏览器窗口样式的解答卡片错位叠放，提示词便签叠在卡组边缘；题目标签与暂停轮播位于首屏底部。首屏下方为最近收录卡带与平台盲评入口。桌面卡片按窗口宽高有限缩放，内容至少撑满窗口；手机自然纵向排列。桌面首屏分隔线正中有滚动引导胶囊，滚动超过60px淡出，手机隐藏。
- **题库**：侧栏为一组导航：全部题目、各分类（图标与题数同排行榜）、细分隔线、模型索引；右侧题目卡片按工作区宽度换行，桌面每行最多三张，末行分配剩余宽度；≥1100px 时单卡最大半行宽，避免单条搜索结果被放大整行；手机保持两列。封面高度上限随视口在 180–280px 之间调整，手机上限 160px。每卡一张预览图、分类（次要色）与最多两个标签（灰）、发布者头像、标题、简述、日期与解答数量；标题行右侧是灰色说明「解答数不计存疑作品」；下方工具栏左侧是搜索，右侧是无标签文字的下拉框（选项自带名称与数量）；模型索引同样是左侧搜索、右侧厂商下拉，说明改为「点击作品直接进入在线预览」。内容较少时页脚仍在工作区底部。
- 平台可用时，题库首位以虚线卡片呈现「下一道题，由你来出」；静态档案不显示该卡片。
- **题库预览**：有解答的题目在平台可用时读取榜单，优先选榜首配置的已验证作品及其小模型；无榜单时优先该题 Astra Pro 作品，否则选择可用截图或其他作品。零作品题不请求榜单，显示「等待第一份答案」；有作品但无可用预览时显示「暂无预览图」。榜首没有小模型时保留作品截图。模型先显示同机位海报，画布就绪后淡入；桌面可随鼠标轻转，手机与减少动态效果偏好下不转动。布局、卡片比例与题目链接保持一致。
- **排行榜**：共用双栏外壳，侧栏视图为「综合」与数据包题目 `category` 各一项（界面显示写作、设计、三维，计数为题数；推理题由 AI 评分，不在排行榜出现，题目页也不显示榜单面板）；比较次数、参与者与上榜数只在侧栏统计里显示；工具栏左侧是搜索模型（数据刷新时保留输入与焦点），右侧依次为领域下拉、题目下拉（仅题型视图，选项带作品数，作品不足的题禁用）、Harness、服务商与计分单位。服务商筛选为全部 / 官方 / 非官方 / 未注明。单题沿用 `#/leaderboard/<题目>`，侧栏停在所属题型。
- **作品页**：侧栏依次为题目信息、作品 / 截图对照 / 排行榜导航，有沙盘的题在细线「全屏查看」下另列三维沙盘与原作展厅（右侧 ↗），然后是模型与厂商数，最后是「题面」：衬线排出的提示词原文，标题行带长短版切换与复制，随侧栏独立滚动；≤760px 题面先露两行，标题行「复制」左侧的「展开」看全文。原「提示词」标签页取消，旧的 `#prompt` 地址回到作品。右侧标题行左侧为「全部作品」与计数，右侧是两张行动卡：「参与盲评」朱红底、斜体衬线 A/B 记号与「可盲评 N 件」，「上传作品」反色墨底与「交一份你的答案」；作品不足或不收投稿时变为灰色描边卡并写明原因，静态档案不显示。工具栏左侧搜索，右侧「精选 / 同门」排列切换（没有同厂商多模型的题不显示）、截图 / 小模型切换、厂商 / Harness / 服务商下拉与排序；>1200px 时控件保持一行、搜索在 160–260px 间让位，放不下时搜索单独一行；≤1200px 搜索单独一行；≤760px 控件排成一行贴边横向滑动。服务商筛选为全部 / 官方 / 非官方 / 未注明，选项带作品数。桌面三列，大屏四列，窄桌面与手机两列。
- **作品卡片**：模型名是标题（15px 粗体），档位等徽标同行；作品自起的名称降为一行灰字，卡片不再显示简介。题目封面作品（`taskCover`，至少三个已验证模型时）固定排在已验证组首位，未筛选、未搜索时占两列两行，左上角朱红「代表」印章，模型名放大，下方一句说明来历（票选或封面规则）；≤1200px 改为整行宽、单行高；筛选或搜索时恢复普通大小。
- **同门排列**：每个厂商一行，左侧 148px 列放厂商标识、名称与「N 个模型 · M 件作品」，右侧作品卡片（248px 宽、封面 1.8:1）横向滑动；作品按模型名称的系列与版本号、再按档位排列，同一模型的作品相邻，换到下一个模型时卡片间多留空并画一个灰色 › 箭头。只有一个模型的厂商合为末行「其他厂商」，不画箭头。不折叠、不放大封面作品，搜索与筛选照常隐藏不匹配的卡片和空行，排序下拉禁用。≤760px 厂商信息改为卡片上方一行，卡片宽约 62% 屏宽并贴边滑动。
- **提示词与作品版本**：同题提示词面板用按钮切换长短原文，复制当前版本。同模型、档位、核验状态与来源的已标注版本结果合为一张卡，尚无作品的版本按钮禁用；并排预览两栏各自选择版本。作品计数保留实际份数，同时显示分组数。
- **分节**：`.collection-heading` / `.block-head` 无衬线标题、灰色计数，右侧只放本页主要操作，没有操作时放灰色说明（题库标题行右侧是与作品页同一个「参与盲评」行动卡，副文字「可盲评 N 件」随筛选变化，没有可评的题时变灰）；以细线划分内容。列表页（题库、模型索引、作品页、排行榜、盲评大厅）的搜索统一放在下方工具栏最左侧，是带描边的输入框，聚焦时描边变为次要色。
- **目录式列表**：盲评题目、我的作品、审核、记录都用清单，不用卡片堆叠。盲评题目只保留每行底部细线，行标题为 16px 无衬线；其他清单保留各自既有样式。悬停只做底色和轻微缩进。
- **全屏舞台**：在线预览与盲评共用 `.viewer`：顶栏 56px、深色作品区、需要时右侧 344px 抽屉（窄屏为底部抽屉）。

## 组件

- **按钮** `.btn`：38px 高、1px 描边、6px 圆角；`.primary` 为反色墨底（深色主题为纸色底）；`.sm` 31px；`.ghost` 透明；`.danger` 朱红字；禁用降为 40% 不透明。
- **芯片** `.chips .chip`：5px 圆角、小号描边标签；选中为墨字、次要色描边与次级底色（`aria-pressed` 或 `aria-current`）。
- **分段控件** `.seg`：主题面板托盘，选中项用次级底色与墨色文字。用于截图条件、试加载尺寸、榜单单位、审核分类（位于「审核」标题右侧）。登录窗口不用分段控件：标题即当前模式，底部「还没有账号？注册 / 已有账号？登录」切换，注册规则写在输入框占位文字里。
- **徽标** `.badge`：等宽小字、4px 圆角；档位用默认样式，「暂定」用虚线。
- **状态徽标** `.status`：已验证实线（卡片中不显示，由分组表达）、未验证虚线灰字、存疑朱红描边。
- **表单**：标签在上、12px；输入框 40px、主题底色，聚焦时次要色描边；错误信息朱红 13px；确认项用 `.confirm` 描边块，未满足前置条件时半透明且不可点。
- **检查清单** `.checks`：每行「图标 + 粗体项名 + 说明」，底部细线；通过为墨色勾、提示为朱红圆点叹号、失败为朱红叉、等待为灰色时钟。
- **对话框** `dialog.sheet`：原生 `<dialog>`，10px 圆角、主题面板底、衬线标题、背景轻微模糊；审核面板为宽版两栏。
- **菜单** `.menu`：主题面板底、8px 圆角、阴影；窄屏导航菜单与未登录账户菜单在顶栏按钮下方展开；已登录头像直接进入个人中心。
- **提示条** `.toast`：底部居中的 6px 圆角提示条，3 秒后淡出。
- **平台提示条** `.platform-notice`：只在前端数据包与平台服务版本不一致时出现在顶栏下方，整宽朱红淡底、细线分隔；朱红圆点 + 粗体「平台功能暂停」+ 说明，右侧「刷新页面」文字按钮，随页面滚走。平台页面自身已说明原因时不重复显示。
- **表情** `.reactions`：只显示有人贴过的表情（5px 圆角标签 + 等宽计数），末尾是无边框添加按钮；自己贴过的用朱红淡底。
- **榜单表格** `table.board`：顶部墨线；前三名名次用朱红衬线（按名次而非行序，搜索后仍正确），其余灰色等宽；分数大号等宽、区间小字；区间横条是 4px 浅色细槽上的区间段与带底色描边的墨色圆点，最宽 260px，虚线标出 1000；区间段截取贯穿本榜刻度的「灰 → 墨」渐变中自己所在的一段，越靠前越深；暂定为空心圆点。综合榜在厂商小字后列出各题型名次（「建模第 1」），不加新标记。
- **未收录模型**：注册表外的模型在厂商小字后加灰色「未收录」（如「Anthropic · 未收录」），悬停说明厂商来自投稿者填写还是按名称推断；推断不出厂商时只显示「未收录模型」，字母图标改为虚线。名称或别名与登记模型相同（忽略大小写、空格、-、_）的投稿直接显示为登记模型。

## 状态与平台页面的视觉口径

- **核验状态**：已验证作品不打标记，按组排在最前；未验证单独成组；存疑成组并默认折叠，封面灰度、标题降为次要色、写明原因，表情冻结。
- **投稿封面**：没有截图时显示「标题 + 截图生成中 / 暂无截图」的文字封面，底纹为极淡的斜线，不放占位插画。
- **盲评大厅**：沿用排行榜结构。侧栏为统计、「随机一组」（按钮下一行灰字说明范围，每组可能换题）、未登录提示和题型视图（全部 / 写作 / 设计 / 三维，计数为可评题数；推理题不进盲评）；右侧标题随视图变化；工具栏左侧搜索题目，右侧写可评与作品不足的题数，输入时只重绘列表。题目行右侧文字为「只评这题」，进入按题盲评。可评题目在前，「作品不足」按存疑分组的方式默认折叠；盲评规则与快捷键放在底部「盲评规则」折叠项，与「计分方法」同一组件。统一称「盲评」，「双盲」只用于说明文字。
- **盲评对战**：两侧只有斜体衬线字母 A / B 与糊名条（读屏读作「匿名作品」），载入层显示大号淡色字母而不使用封面（避免透露身份）；载入状态用小圆点表示（灰色载入中、墨色已就绪），不用文字胶囊。手机上匿名阶段不重复窗格标题行，「AI 生成」与重新载入并入 A / B 切换器一行。匿名阶段名字的位置盖一条「糊名」条（朱红细框、斜纹淡底、衬线「糊 名」与灰字「投票后拆封」）；投票揭晓时身份淡入，糊名条向右滑出一次（0.6s，重绘不重播）。你选中的一侧标题栏顶部一道 2px 朱红线，名字后盖一枚倾斜的「所选」小印；选「不分伯仲」时不盖；跳过不揭晓，糊名条保留，标题下显示「第 N 组 · 已跳过」。手机上揭晓时标题行带着拆封动画出现。投票条居中三个同样式按钮，快捷键以键帽样式标注。桌面两窗格之间是 9px 拖动区上的 1px 分隔线，悬停时出现带左右收起箭头的胶囊把手，拖动时顶部显示「A 64 · B 36」墨底读数；收起的一侧为 44px 窄栏（字母、载入点、竖排「展开作品 A」）。随机盲评的顶栏标题后带灰色小胶囊「随机 · 全部题目 / N 道题」，右侧先是「随机换题 / 只评本题」两键分段（手机缩为「随机 / 本题」，隐藏胶囊），换题的那一组在窗格上方居中滑出一条「这一组换成了 X · 看提示词」，4.5 秒后淡出。顶栏「提示词」后是三键分段控件（两个小方框，实心为在看的作品）；窗格标题栏右侧依次为「控件」（窄窗格只留图标）、只看这件 / 恢复并排与重新载入。已评完或暂停时使用与榜单相同的虚线空状态。不计票的读者进入对战前看到 400px 的计票提示弹窗：两行对比，「体验」行为虚线框与虚线字签，「计票」行为浅朱红底与倾斜的朱红「计票」小印（同「所选」印）；底部「先体验」与主按钮「登录后开始 →」分两栏（1 : 1.5），未登录时另有「还没有账号？注册」。
- **发起题目**：共用双栏外壳；主表单按标题、简述、题目类型、所属领域、提示词、提交格式排列。类型显示写作 / 推理 / 设计 / 三维，四张单选卡片共用图标、字号、间距与墨灰选中状态，≤760px 单列。发起、审核通过和编辑题目都复用 `question-fields.js` 的类型卡片与领域控件；审核通过弹窗与编辑弹窗同为 720px 上限。领域共 26 项（人文与社会含哲学），按理工与健康、人文与社会、空间与产品、生活与娱乐四组排列；桌面左侧为组名，右侧为自动换行的复选项，≤460px 组名放到选项上方。沿用表单的背景、细描边、圆角和墨色勾选，不按领域增加颜色；显示「已选 N / 2」，选满后禁用其他项，取消一项即可更换。写作与推理固定纯文本 / Markdown，设计和三维固定单个 HTML 文件。右侧为填写说明。
- **投稿**：三个编号步骤纵向排列，题目固定在侧栏；未解锁步骤半透明，试加载舞台按真实视口尺寸渲染后等比缩放。拖拽区下只留一行最常见的文件要求，其余收进「全部文件要求」；上传中拖拽区换成带「取消」的进度卡。作品信息只把必填项摆在外面，其余收进默认折叠的「补充信息」（编辑已有内容时展开）。服务商下拉必填，只选官方 / 非官方；Harness 只记名称，可手填并有相似名称提示，不再有版本。
- **阶段条** `.timeline`：投稿侧栏「提交之后」竖排，提交完成页横排（`.is-row`，最宽 720px）。已完成为次要色实心点，当前阶段是带浅色外圈的墨点与墨色标题，未到阶段文字转灰；失败阶段为朱红。投稿与发起题目共用 `stageTrack`。
- **个人中心**：侧栏为 概览 / 我的作品 / 我的题目 / 审核（管理员），审核也使用这一侧栏。管理组为全部作品，高级管理员另有全部题目与全部成员；成员行以头像代替缩略图，角色弹窗左侧为账号与参与情况、右侧为三种角色的权限卡，降级时变化说明与保存按钮用警示色。概览资料区显示头像、20px 昵称与「编辑昵称」幽灵按钮、账号与加入时间，右侧「退出登录」为灰色文字按钮；编辑时换成输入框 +「保存」「取消」。近一年活跃图按周排成横向滚动的日格，用墨色由浅至深表示五档数量；表情统计展示六种表情及计数。我的作品 / 我的题目 / 审核各占一个视图，标题右侧放本视图的操作（上传作品、发起题目、审核分类）。清单行标题跳转预览，右侧放操作按钮。
- **作品管理**：工具栏左侧搜索，右侧题目、盲评状态和排序，下方审核状态筛选带数量；只重绘结果，输入保持焦点。清单为缩略图、模型与标题 / 发布者、三项状态及「管理」按钮，存疑与拒绝用朱红，其余用墨灰。管理弹窗桌面两栏（左预览与记录、右信息和展示开关），手机单栏；只有中间内容滚动，取消与保存固定在底部。展示开关独立，不能操作时说明原因。本人作品可以保存信息，审核按钮及展示开关禁用；删除仅高级管理员显示。手机缩略图为 76px，管理按钮移至文字下一行，筛选芯片可横滑。

## 动效

- 路由切换：旧画面保留到新页面画好并拿到首批数据（最多 300ms），然后 0.25s 交叉淡入，不移动卡片画布。顶栏和侧栏单独过渡，同一板块内看起来不动。超过 300ms 的页面先显示自己的载入状态，数据到了原地补上，不再淡入。回到看过的页面时先显示上次的内容，再静默刷新。同页重画（筛选、登录状态变化）不淡入。减少动态效果时直接切换，没有淡入。主题切换同样是 0.25s 交叉淡入。展厅 / 沙盘的载入占位带顶栏。图片解码后淡入。
- 浮层：菜单 0.18s、对话框 0.28s、提示条 0.3s，全部只用 `opacity` 与 `transform`。
- 悬停：按钮与链接只变色、箭头右移 2–3px；列表行底色渐变。
- 尊重 `prefers-reduced-motion`：全部动画与过渡降到 0.01ms。

## 响应式

布局断点 1200 / 950 / 760 / 460px，作品网格在 ≥1600px 四列。≤1200px 缩窄侧栏、投稿说明移到下方；≤950px 顶栏入口收进账号菜单；≤760px 侧栏变成文档顶部，题目导航和板块视图导航（`.section-nav`，含题库分类）横向滑动；≤460px 两列紧凑作品卡片。原预览舞台的 860px A / B 切换、640px 榜单列隐藏与表单断点继续保留。
