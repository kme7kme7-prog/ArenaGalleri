# Gallery 产品行为

首页组织同题解答卡组、提示词便签和最近收录。题目有两条轴：题目类型（存储值文学 / 推理 / 静态网页 / 建模，界面显示为写作 / 推理 / 设计 / 三维）决定提交格式、评判方式和排行榜分组；写作与推理提交纯文本 / Markdown。写作、设计、三维由盲评计分；推理（数学、逻辑、哲学）改由 AI 评分，不进盲评池和排行榜，评分开放前作品卡显示「AI 评分待开放」，作品带 `aiScore`（score、max、judge、rationale）时显示分数。所属领域（`domains`，每题 1–2 个，如数学、化学、建筑）用于浏览和领域排行。设计覆盖页面布局、界面交互与数据可视化，仍提交单个 HTML 文件；分类存储值、原有网址和计分分组沿用。题库默认使用「推荐（热门与探索）」：每六题以三个热门位置穿插零作品、低模型覆盖和近七天新题，候选不足时补位；热度结合不同已验证模型、受限的历史作品量和按时间衰减的近期投稿，探索池六小时轮换，可点「换一批」。搜索筛选后在匹配集合内重新混排，卡片显示推荐理由；仍可按时间、作品数或名称排序，保留读者已明确选择的偏好。规则见[题库推荐](question-recommendations.md)；按类型、领域、关键词和模型筛选，类型与领域可以叠加并写进网址（`#/questions/<类型>/<领域>`，任一可省）。题目不设标签：题库与盲评大厅的搜索匹配标题、简述、类型、领域和全部版本的提示词原文，空格分隔的每个词都须出现，字母不分大小写并忽略空格、点、连字符和下划线（threejs 可找到 Three.js）。题库搜索时，标题、简述、类型或领域已包含全部词的题目排在前面，只在提示词里命中的排在后面，并在卡片上显示命中处前后的一小段提示词原文；各组内仍按所选排序。数据包与后台保留的旧 `tags` 字段不再展示，公开目录也不输出。领域词表优先取后台 bootstrap 的 `domains`，没有时用 `site/categories.js` 的默认表；分组选项优先取 `domainGroups`，旧后端只返回词表时按默认分组组织允许的选项。默认共 26 个领域，按理工与健康、人文与社会、空间与产品、生活与娱乐四组展示；分组只组织表单，不是新的题目属性。题库与排行榜只展示已有题目的领域。排行榜在综合与各类型之外可再按领域收窄（`#/leaderboard/<领域>` 或 `#/leaderboard/<类型>/<领域>`），领域内少于 2 题或 50 次有效比较时提示样本不足；有效比较只数实际计分的比较；题目页支持作品搜索、来源筛选、模型预览、截图对照、在线运行和并排比较。

成员分四级：Lv0 新注册，Lv1 认证成员（通过资格考试），Lv2 管理员，Lv3 高级管理员。Lv0 可盲评、重提自己被驳回的旧题，但不能发起新题或上传作品，在对应入口看到资格考试引导。资格考试（`#/exam`）由管理员挑选的标准对组成，每组两件质量差距明显的作品，选出更好的一件；题量与及格数取自服务端，不限次数与时间，交卷后只公布总分，不揭晓模型、不计榜；通过升为 Lv1，中途离开保留进度。盲评与考试都在两侧作品报告就绪后才计时：投票至少看 5 秒、跳过至少 3 秒，以服务端给的 `voteAllowedAt`/`skipAllowedAt` 为准，页面隐藏时不累计。未登录或未绑定邮箱的票计入大众榜；快速连选和访客间隔需完成人机验证（Lv2 及以上免验证）。

排行榜分为大众榜与精选榜。大众榜取全部有效比较；精选榜（`#/leaderboard/curated[/<分区>]`）只统计管理员选入精选的题目、且只算 Lv1 及以上成员的盲评选择，分区、总榜和「空 / 收集中 / 从零开始」状态由服务端给出。精选题在盲评题目列表带标记。公开榜单成功生成后复用十分钟，页面按 nextUpdateAt 刷新，隐藏时暂停，离开后停止；审核撤下与换包可提前使快照失效。推理题不进盲评池和榜单。

排行榜按当前范围和计分单位的作品列计数，默认隐藏不足5件作品的模型或配置，5件保留。勾选“显示作品少于 5 件的条目”可查看，选择保存在当前浏览器；已评分行和未计分列表均适用。只改变显示，评分、原名次与比较数不变；“暂定”仍按比较次数标记，不因作品数或开关改变。上榜数量反映当前显示条目，全部隐藏时保留开关和恢复说明。

服务商只有官方 / 非官方，未填写显示「未注明」。官方指模型厂商自己的 API、网页或 App；聚合平台、云厂商、自部署等为非官方。题目页与排行榜按这三项筛选，旧平台 ID 或手填名称显示为非官方；排行榜仅计入两件作品的来源都符合筛选的比较。

题目、作品预览、展厅/沙盘、上传和盲评对局在顶栏提供统一的「返回 X」，返回读者进入时的页面；直接打开或从下级返回时退回上级。窄屏只显示「返回」。题库分类保留在网址中，浏览器后退、前进及返回上一历史条目时恢复原滚动位置。

完整提示词继续展示并支持复制。作品卡片和指南不提供私有源码、项目 README 或数据仓库跳转入口。必要的数据包协议标识保留在运行数据中。

题目页侧栏常驻「题面」（提示词原文，可切换长短版并复制），标题行右侧是「参与盲评」与「上传作品」。每个模型（不分推理档位）先展示一件代表作，同组其余作品折叠，模型名一行右侧的「+N 件」按钮可展开，展开的同组卡片左侧共用一条灰色边线；工具栏的「精选 / 同门」切换排列（记住读者的选择）：同门按厂商分行，每家作品按模型名称的系列与版本号（数字按数值比较，许多模型没有登记发布月份）、再按推理档位排开，换代处有箭头，只有一个模型的厂商合在末行「其他厂商」，存疑作品仍折叠在最后；同门不折叠、不放大封面作品，排序暂停使用；没有任何厂商出两个模型的题不显示这个切换；后台票选出的代表作带「代表作」标记；本题封面作品在至少三个已验证模型时排在最前并放大，盖「代表」印章并说明来历；筛选或搜索时列出全部匹配作品、恢复普通大小，数量显示为「X 个模型 · Y 件作品」。题库封面优先采用高级管理员在题目上指定的作品；未指定时，代表作与封面采用后台按盲评票选出的作品（`platform.featured`）。没有票选结果时，代表作按一轮且无人工介入、推理档位高、收录早排序，封面依次取 Claude Opus 5.5 Max、GPT-6 Astra Max，再没有则显示灰色占位。多轮或有人工介入的作品带「多轮」「人工介入」标签，只展示，不参与盲评；盲评大厅显示「可盲评 N 件」。选择逻辑见 `site/featured.js`。

同一道题的长短提示词通过按钮切换，复制使用当前版本。标明提示词版本的结果按相同模型、推理档位和来源合为一张卡片，按钮切换实际作品；并排预览中每一栏独立切换。每份作品保留自己的 ID，尚未收录的版本按钮禁用。

题目可以附参考图（`references`，与提示词一起按顺序交给每个模型，作为附件或放进工作区均可）。题面在提示词原文之前显示参考图：侧栏较窄时首张通栏并标注说明、其余每行四张，较宽的栏位与手机一排最多五张；下方常驻「图片来源」署名。点击任一张进入站点原有的大图层，顶栏显示文件名并可单张下载，图下胶片条切换全部参考图；「全部下载」在浏览器内打包为 `<题目ID>-references.zip`，文件名与题面一致，失败时改为逐张下载。提示词原文不改，原文里写出的 `references/文件名` 可点开对应图片。盲评的提示词抽屉、上传作品页「查看本题提示词」（提示按顺序一并提供给模型）与题目审核卡片显示同一组图片；题库卡片只加「参考图 N」。大图打开时盲评的 A / D / S 快捷键不生效，Esc 只关闭大图。

盲评与并排预览默认折叠作品的小型悬浮控件，控件的 DOM 与交互状态保留。并排预览至少一侧检测到控件时，顶栏显示「显示作品控件」，点击同时切换两侧；更换或重载一侧保留显隐选择，重新进入并排恢复默认隐藏。盲评改为每件作品各自的「控件」按钮（该作品检测到控件后才出现，手机放在 A / B 切换行，作用于当前作品），换组恢复默认隐藏。桌面盲评的 A、B 宽度可调：拖动中间分隔条（或聚焦后用方向键），拖到边缘时一侧收成窄栏、另一件铺满，点窄栏恢复；顶栏三个布局键与键盘 1 / 2 / 3 切换只看 A / 并排 / 只看 B，双击分隔条复位。收起的作品不重载，每组开始复位为 50 : 50；只看一件时不限制投票。超过 6 个悬浮块或本次检测覆盖页面 40% 以上时沿用脚本的保护规则，不折叠这些元素。单栏浏览与新窗口保持作品原有控件。

账号、发起题目、投稿、核验、表情、盲评、榜单、个人中心和审核通过独立后台实现。前端不保存投票数据库或承担计分。只有默认相对 API 返回不存在的独立静态站点使用包内档案；已配置后台的站点不因临时故障回退旧目录。

题库先展示标题、导航与卡片骨架，公开目录返回后立即显示题目。账号和统计独立加载，不挡住题库与排行榜；未知统计显示等待状态，不当作零。目录首次失败在内容区域提供重试，刷新失败保留已经验证的内容。各初始化读取单次最多等待15秒；网络失败、超时、响应不是 JSON 或限流时，按1、3、6秒退避自动再读，最多3次（限流至少等到服务端要求的时间），整次读取不超过45秒，期间仍显示加载中，用尽后才显示连接失败；其他服务端错误不自动再读。之后启动恢复再自动尝试一次；限流按服务端等待时间倒计时，期间不发送重连请求。之后可手动重连，恢复网络或回到页面时也会尝试恢复，无需整页刷新。账号确认过期或切换时清理私有内容；同一账号的迟到统计不清空正在填写的表单。未提供平台接口的静态站点不自动重试；版本不兼容仍暂停平台功能并要求刷新页面。

管理员更正已投稿作品的模型、厂商或推理档位后，同一内容的历史盲评按更正后的归属计分，更正前已打开的对局仍可完成。原投票、身份快照和来源标签保留，更正另有审计记录；标题、简介等修改不改变计分归属。数据包作品沿用版本化的来源身份。

单独提交题目需成功计票满 100 次，或已提交且未删除的作品满 10 件，满足任一即可；待审核作品计入，跳过、未计票的盲评和试上传不计。附带有效示例结果可直接发起，不受此门槛限制；普通管理员和高级管理员均豁免。登录、绑定邮箱、待审数量与内容审核规则继续适用。发起页提前显示两项进度和剩余数量，未达标时弹窗提供继续填写并附示例、去盲评、去题库上传的入口；单独提交前读取最新资格，后端再次校验，拒绝不创建题目。关闭提示保留本页表单，离开页面不承诺保留。

盲评有两种出题方式：按题（`#/arena/<题目>`，每组都是这道题）与随机（`#/arena/random`，每一组都可能换题）。题库标题行的「参与盲评」和盲评大厅侧栏的「随机一组」进入随机，范围是启动页面当时显示的题目（题库的搜索与分类、大厅的分类与搜索）中可盲评的题；随机每组从范围里均等抽一道题，不连续抽同一题，读者评完或当前无法配对的题自动略过，范围内全部评完才提示；若仍有暂时无法配对的题，提示当前没有可继续盲评的组合。随机换题时顶部提示换了哪道题，提示词抽屉随题更新；对战页顶栏可在「随机换题」与「只评本题」间切换，后者停在当前这道题。配对仍由后台按题完成，随机只是前端轮流选题。揭晓过的作品进入软冷却：读者再评 6 组（跨题累计，跳过不算）或过 15 分钟，先到先解除，由后台按账号计算，未登录只回避上一组。冷却只是优先避开，从不拦住读者：只评本题时优先出不含冷却作品的组合，没有就照常出；随机模式带 `avoidCooling` 请求，某题剩下的组合都含冷却作品（后台 409 `cooling`）时这一组先略过该题，范围内全部冷却时再不带该参数照常抽。跳过不揭晓身份，后台也不返回。每组投票或跳过后立即预取下一组配对信息；桌面和手机都在点击「下一组」后先卸载当前作品，再加载新作品，结果停留期间不运行下一组作品。切换出题方式或登录账号变化时丢弃预取。盲评仅对普通用户回避本人投稿；普通管理员与高级管理员可评本人投稿，符合计票条件的选择正常进入榜单。所有角色均按同题不同模型配置配对，登录并绑定邮箱后计票，每对作品每人计一次。未登录或未绑定邮箱的读者进入任一题盲评时，抽取作品前提示一次（每个标签页一次）「登录后投票才计入」：可先体验，或登录 / 注册 / 绑定邮箱后再开始，这样这一轮的选择会计票。为尽快确定新模型的位置，高级管理员可在盲评大厅侧栏「固定模型」选一个模型（含全部推理档位）：之后每组必有它的一件作品，左右随机，对手由后台从其他模型中抽取并优先比较次数多的配置；冷却与回避上一组只作用于对手。大厅与随机范围只列出它有作品的题，该模型在某题无可配对作品时后台返回 409 `pinned-absent`，随机模式略过该题。选择照常计入公开榜单，后台在对局上记录 `pin` 以便日后区分；对战页顶栏显示「固定」标记，点击退出，揭晓后显示本次累计胜平负及它在综合模型榜上的名次与分数。固定只保存在当前标签页，不写入网址；其他角色带 `pin` 请求返回 403。

注册需先验证邮箱：发送验证码时完成人机验证，注册提交用户名、密码、邮箱与验证码。注册、账号绑定和找回密码发送成功后，提示未收到时检查垃圾邮件箱。旧账号仍可登录和浏览，发起题目、上传或贴表情前需绑定邮箱；未绑定邮箱的双盲选择不计票，界面提供绑定入口。个人中心可验证新邮箱后换绑。绑定状态只使用当前会话数据，旧接口缺省按已绑定处理。

发起题目先填写题目信息（作答形式必选、所属领域必选 1–2 个，不再填写标签；提交格式跟随形式：文本固定为纯文本 / Markdown（.md 由后台排版，支持标题、列表、引用、代码、表格与 LaTeX 公式，含公式的页面由后台加载 KaTeX 显示；.txt 不解析），网页与三维可选纯 HTML 与 Vite；管理员通过题目时可修正形式与领域），完整提示词下方可选上传参考图（后端 bootstrap 提供 `limits.referenceCount` / `referenceBytes` 时启用，PNG / JPEG / WebP）：每张选中即单独上传并显示进度，文件名按顺序自动编为 `NN-名称.扩展名`，可改名称、写说明、前后移动或移除；「插入参考图说明」把「请参考提供的 N 张图片完成，按顺序分别为：」及说明列表写进提示词，再次插入会就地改写这一节；提示词与图片数量对不上时给出不阻止提交的提醒；有图时填写图片来源并声明有权公开。图片仍在上传或上传失败时不能提交。高级管理员编辑题目时使用同一编辑器，已公开且有作品的题目参考图与提示词一样只读。然后可在达到资格后「单独提交题目」，也可不受参与门槛限制选择「附上示例结果」，用共用的上传步骤（`site/submit.js` 的 `uploadFlow`）附上一份用该提示词生成的结果再一起提交（依赖后端：无作品的 `POST /api/questions`，以及 `__new__` 草稿与带 `work` 的同一接口）。附示例这一步单独占一条浏览记录：浏览器后退、01 标题行的「修改题目」或侧栏「01 题目信息」回到表单，已上传的文件、试加载确认和结果信息都保留，表单顶部说明保留内容并以「回到示例结果」为主按钮，浏览器前进同样回到示例；此时单独提交会先确认丢弃示例。只改标题、简述、领域时全部保留；改了提示词则保留文件，但清空试加载确认与声明勾选并提示可重新选择文件；改了形式致格式不符则移除文件、保留结果信息。上传中返回先询问，默认继续上传。新题目一律由管理员人工审核，通过后才进入题库；附带的示例结果同时走内容审核，题目通过且内容放行后才进入作品核验。提交完成页的阶段条同时显示题目审核与示例结果审核的进度。提交后作者在「我的题目」看到等待人工审核 / 未通过，未通过时理由以朱批「审核意见」显示，通过前没有公开页面；未公开的题目可以连同示例结果撤回。从未公开过的未通过题目可以「修改后重新提交」（`#/new/<题目>`）：沿用发起表单并带上原内容，审核意见置顶，改过的标题、简述、提示词标「已修改」，示例结果默认保留、可选择移除；不再检查发起资格，但重新计入待审数量，内容与上次相同时后端拒绝。重提后显示「第 N 次提交」和可展开的上次意见；公开后被撤下的题目只显示原因，不能修改。管理员在「审核 · 题目」里先看待审题目（最早的在前），可预览示例结果后通过、拒绝（必须写理由）或删除；重新提交的题目标「重新提交 · 第 N 次」，并显示上次意见（审核人与日期）、本次改动的字段与提示词逐行对比；侧栏与菜单的待办数包含待审题目。后端没有题目审核接口时，这个标签页只显示提示，作品审核照常。

「我的作品」按审核中、等待核验、已验证、存疑 / 未通过筛选，并逐件显示内容审核、题目审核和核验阶段。普通成员默认最多 8 件作品同时等待核验；已有至少 3 件未删除的已核验作品且近 90 天无存疑记录时，沿用 20 件上限。普通与高级管理员不限制等待核验数量。上传按钮旁显示等待核验名额，以后端个人上限为准；满额时给出原因，管理员不显示有限名额，上传页也不拦截。未经人工决定的作品只向作者和管理员开放预览，不能把自动审核通过称为已公开。核验通过也不自动保证进入盲评。

站内题目和作品不再区分馆藏 / 社区，只按发布者区分：所有账号（含高级与普通管理员）发布的题目与作品公开显示个人昵称和头像；数据包里的题目和作品没有个人发布者，显示站点名并视为已通过。管理员发布的作品跳过自动内容审查直接进入核验，发起的题目也进入题目审核。权限分三级：高级管理员（网站运营）可做全部操作；普通管理员可查阅全部作品、保存作品信息（含本人作品），对他人作品做内容审核、核验与展示决定，含同样限制的批量操作；自己的作品由其他管理员作审核与展示决定。普通管理员不能审核或编辑题目、删除题目和作品、管理角色。管理员可批量审核题目、内容和核验，每件独立处理，失败项保持选中并显示理由。审核弹窗可就地修改作品文字和登记信息，也可只保存信息；管理员修改保留内容审核决定。高级管理员在审核页「管理 · 全部题目」查看全部题目（筛选布局同全部作品：搜索题目、提示词或发布者，按题目类型、领域筛选与排序，按公开 / 待审核 / 未公开 / 不收投稿分组计数；显示发布者与作品、盲评池情况），可编辑标题、简述、形式、领域、提示词、投稿开关与封面作品，撤下或恢复，删除没有投票的题目；已公开且有作品的提示词只读，保存不改变审核状态。题目管理可直接跳转到本题作品。题库封面先用管理员指定的作品，其次票选代表作，再按默认规则。
