# 卡片模型预览

卡片直接消费私有包中的 `.sbox` 模型、WebP 海报和真实截图，不在前端仓库提交这些资源。可见卡片优先加载，正常模型读取不重新构建原作。

`preview-model.js` 读取压缩模型；`result-previews.js` 管理卡片渲染；`scene-resources.js` 回收场景资源。沙盘与回退加载按需导入对应模块。`assets/scenes/` 下的 `.sbox` 与海报默认仍从画廊源站读取。`mediaCdnBaseUrl` 为非空地址时，这些相对路径和 API `/media/` 改从该主机读取，例如 `https://media.arenaofbias.icu`。新发布的场景模型要先按同一 `assets/scenes/...` 键进入该桶。

海报指纹覆盖模型、场景配置和渲染实现。缺失或过期时本地构建提示并回退截图；发布环境设置 `CI=1` 后构建和收录检查失败。仅确认文件存在不能证明海报与当前模型匹配。

修改模型、预览渲染代码或相关 Three.js 版本后，在私有数据仓库生成对应海报并发布新包，再更新本地配置。原作在线运行文件、画质与交互不因卡片预览而改变。

平台注册投稿可通过后端提供 `previewModel`、`previewPoster` 和 `previewMode`，或独立展示图 `previewCapture`。这些媒体由后端保存，前端只读取；后端清单核对原入口、模型和海报的 SHA-256，源文件变化后旧适配不再进入 DTO。已经烘焙的跨源模型直接读取，不把跨源原作送进卡片提取器。投稿适配海报也须使用当前 Gallery 渲染器，取景与实时模型一致。

截图选择依次为独立展示图、桌面首屏、作者图库封面和其他截图（含手机）；卡片完整展示图片。题库封面保留管理员指定、票选、Opus 5.5 Max 和 Astra Max 的优先顺序；候选没有可用图片或模型时，选择其他有媒体的公开作品，质疑作品不参与。


代表卡只给当前可见的海报或截图 `loading="eager"` 与 `fetchpriority="high"`；其余卡片以及隐藏的截图仍延迟加载。截图模式保留完整图像比例，不另裁切画面。

批量投稿预览使用后台的 `bake-upload-previews.mjs` 与 `bake-upload-captures.mjs`。模型沿用数据仓提取器、sbox压缩与当前Gallery海报渲染；无法可信导出、遗漏主体或极大模型采用真实默认截图，不制造替代几何。逐件复核桌面及手机卡片后，再由后台清单绑定原入口和媒体摘要发布。原作与真实截图不因预览适配而改变。

反馈复核要对照加载完成后的原作默认画面，检查岛体、房屋、屋顶、城市两岸以及船体和索具是否完整。异步分帧建模可以在后台提取副本中延长等待；GPU水面可以保留原网格并使用有来源的静态颜色。已有海面不重复添加辅助平面，避免重叠条纹。截图/小模型切换、海报淡出后的实时取景以及手机卡片均须目检；只有渲染成功或包体变小不能证明适配完成。

模型投稿也可以同时提供后台校验过的独立截图。切换到截图时优先使用这张720px展示图，完整等比显示；小模型模式使用配套透明海报及实时模型。可选截图摘要失效时回退原有截图，模型仍须通过自身校验；源入口变更后两种适配都停止展示。
